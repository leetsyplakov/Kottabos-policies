# Kottabos-policies

Privacy Policy and Terms of Use for the **Kottabos** iOS app, served via GitHub
Pages. Static HTML (no Jekyll — `.nojekyll`), mirroring the layout of the other
app policy sites.

- Home:    https://leetsyplakov.github.io/Kottabos-policies/
- Privacy: https://leetsyplakov.github.io/Kottabos-policies/privacy
- Terms:   https://leetsyplakov.github.io/Kottabos-policies/terms

Source of truth for the text is `docs/privacy.md` and `docs/terms.md` in the
private `Kottabos` repo; update both if the policy changes.
